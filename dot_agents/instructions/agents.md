## Agent workflow

- Launch implementation and review agents in a new Herdr tab, with the
  implementation agent in the left pane and the review agent in the right pane.
- Agents inherit the parent's model and reasoning effort unless the user
  specifies otherwise.
- Review code changes that affect behavior or design, and review changes when
  the user requests it. Reviews may be skipped for minor configuration or
  wording changes. Committing or pushing already reviewed changes does not
  require another review.
